QUICK RECOVERY

Ask Codex: "Restore Working V1 from working-v1-2026-11-09."

To make a separate recovery checkout yourself, first quit Sarween, then run
these commands from an existing clone:

    git fetch origin --tags
    git worktree add ../Sarween-Working-V1 working-v1-2026-11-09
    cd ../Sarween-Working-V1
    conda activate py_arm
    python main.py --dev-no-login

The recovery checkout is separate from ongoing development. Current Mac
calibration and hardware profiles normally remain available automatically in
~/Library/Application Support/Sarween, independently of the Git checkout.
If the checkout already exists, open it instead of running worktree add again.

If a future Foundry module change also needs reverting, restore module.js,
module.json, capture_logic.mjs, movement_logic.mjs and viewport_markers/ from
this tag to FoundryVTT/Data/modules/sarween, keeping a backup of the installed
module first. Then reload Foundry. The module at this checkpoint matches the
one installed during the successful live test.
